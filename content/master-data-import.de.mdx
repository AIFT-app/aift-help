# Stammdaten importieren

Statt Partner und Kategorien einzeln einzutippen, können Sie sie **per Tabelle in großen Mengen importieren**. Laden Sie eine `.xlsx`-, `.xls`- oder `.csv`-Datei hoch, und AI Finance Team erkennt die Spalten, zeigt Ihnen genau, was erstellt wird, und fügt die neuen Datensätze hinzu - bereits vorhandene bleiben unangetastet.

Das ist ideal beim Onboarding eines neuen Mandanten: Exportieren Sie die Partner- oder Kategorienliste aus dem bisherigen System (oder einer Buchhaltungstabelle) und bringen Sie sie mit wenigen Klicks ein.

## Was Sie importieren können

Der Import befindet sich auf diesen **Stammdaten**-Seiten, die jeweils eine Art von Datensatz importieren:

- **Partner**: Ihre verifizierte Partnerliste (Stammdaten → **Partner**)
- **Rechnungskategorien**: die Kategorien zur Kodierung von Rechnungspositionen (Stammdaten → **Buchhaltungskategorien** → Reiter **Rechnung**)
- **Cashflow-Kategorien**: die Kategorien zur Kodierung von Banktransaktionen (Stammdaten → **Buchhaltungskategorien** → Reiter **Cashflow**)
- **Eigene Kategorielisten**: die Kategorien einer Ihrer eigenen Listen (Stammdaten → **Eigene Kategorien**, dann die Liste öffnen). Siehe [Eigene Kategorien](/custom-categories).

Auf jeder dieser Seiten finden Sie oben eine Schaltfläche **Importieren**. Ein Import verarbeitet jeweils ein Ziel: Die Seite, von der aus Sie starten, bestimmt, was Sie importieren.

Beim Einrichten eines neuen Arbeitsbereichs bietet der Schritt **Kategorien** die Option **Eigene Liste hochladen** an. Sie führt denselben Import für Rechnungskategorien aus, mit denselben Schritten.

> Die Schaltfläche **Importieren** sehen die Mitglieder der Kanzlei. Zum Anlegen der Datensätze braucht es die Berechtigung **Stammdaten bearbeiten**, die die Rollen **Buchhalter-Admin** und **Buchhalter** standardmäßig haben. Siehe [Rollen & Berechtigungen](/roles-and-permissions).

## Bevor Sie beginnen

- Halten Sie Ihre Daten in einer einzigen Tabelle bereit: **.xlsx**, **.xls** oder **.csv**. Die erste Zeile sollte die Spaltenüberschriften enthalten (zum Beispiel `Name`, `Steuernummer`, `Land`).
- Ein Datensatz pro Zeile - aus jeder Zeile wird ein Partner oder eine Kategorie.
- Die Datei wird **in Ihrem Browser** gelesen; sie wird nicht hochgeladen oder gespeichert. Sonderzeichen werden automatisch verarbeitet.

## Eine Tabelle importieren

1. Öffnen Sie die entsprechende Seite (Stammdaten → **Partner**, oder Stammdaten → **Buchhaltungskategorien** und dort den Reiter **Rechnung** oder **Cashflow**) und klicken Sie auf **Importieren**.
2. **Hochladen**: Klicken Sie auf **Tabellendatei auswählen** und wählen Sie Ihre Datei, oder ziehen Sie die Datei auf das Feld. AI Finance Team liest sie und erkennt die Spalten.
3. **Spalten zuordnen**: Jedes Feld (Name, Steuernummer, Land, Adresse, …) wird einer Spalte aus Ihrer Datei zugeordnet. Prüfen Sie die Vorschläge und korrigieren Sie falsche Zuordnungen. Pflichtfelder sind mit einem Sternchen (`*`) markiert und müssen zugeordnet werden, bevor Sie fortfahren können. Klicken Sie auf **Weiter**.
4. **Prüfen**: Jede Zeile der Datei erscheint in einer Tabelle. Die Spalte **Status** zeigt, was mit ihr geschieht (**Erstellen**, **Vorhanden**, **Mehrdeutig** oder **Fehler**), die Spalte **Hinweis** den Grund, wo es einen gibt. Die Zeilen, die der Import anlegen kann, sind von Anfang an angehakt; die übrigen sind grau und lassen sich nicht anhaken. Entfernen Sie den Haken bei Zeilen, die Sie nicht wollen, und korrigieren Sie einen Namen vor dem Anlegen mit **F2**. Beim Import von Kategorien prüfen Sie auch die Richtung jeder Zeile. Angelegt werden nur die angehakten Zeilen. Das ist die Tabellenoberfläche, mit Suche, Spaltenfiltern und Tastenkürzeln; siehe [Arbeiten in der Tabellenoberfläche](/spreadsheet-interface).
5. Klicken Sie auf **Anlegen**, um die angehakten Zeilen anzulegen. Nach Abschluss erscheint zum Beispiel „42 Datensätze erstellt.“. Stellt sich in diesem Moment heraus, dass eine Zeile schon vorhanden ist (zum Beispiel weil ihr geänderter Name zu einem vorhandenen Datensatz passt), wird sie ausgelassen, und eine Zeile nennt, wie viele Zeilen ausgelassen wurden. Klicken Sie auf **Schließen**.

Im Schritt **Prüfen** führt **Zurück** zur Spaltenzuordnung. In den ersten beiden Schritten verwirft **Abbrechen** den gesamten Import. Sobald eine Datei geladen ist, schließt Esc oder ein Klick neben den Dialog ihn nicht, so geht die Datei nicht versehentlich verloren.

## Wie Spalten erkannt werden

AI Finance Team nutzt KI, um die Überschriften Ihrer Tabelle den richtigen Feldern zuzuordnen, sodass eine Spalte namens `Partnernév`, `Vendor` oder `Lieferantenname` gleichermaßen als **Name** verstanden wird. Die endgültige Entscheidung treffen immer Sie:

- Öffnen Sie das Dropdown eines Feldes, um eine andere Spalte zu wählen, oder wählen Sie **Nicht verwenden**, um das Feld leer zu lassen.
- Pflichtfelder (wie **Name**) müssen zugeordnet werden; der Assistent lässt Sie sonst nicht fortfahren.

Wenn die KI keine sichere Zuordnung findet, dient eine integrierte Liste gängiger Überschriftennamen (in mehreren Sprachen) als Rückfall, sodass die Erkennung trotzdem funktioniert.

## Was erstellt und was übersprungen wird

Der Import **erstellt ausschließlich neue Datensätze. Er überschreibt oder bearbeitet niemals vorhandene.** Im Schritt **Prüfen** erhält jede Zeile einen von vier Status:

- **Erstellen**: ein wirklich neuer Datensatz. Die Zeile ist von Anfang an angehakt und wird angelegt, wenn sie beim Klick auf **Anlegen** noch angehakt ist.
- **Vorhanden**: Ein passender Datensatz ist bereits im Arbeitsbereich, daher wird die Zeile **übersprungen** (der vorhandene Datensatz bleibt genau so, wie er ist). Eine Zeile, die eine frühere Zeile derselben Datei wiederholt, erhält ebenfalls **Vorhanden**, mit dem Hinweis „Duplikat in der Datei“.
- **Mehrdeutig**: Die Zeile passt zu mehr als einem vorhandenen Datensatz und wird sicherheitshalber übersprungen. Lösen Sie diese anschließend von Hand auf.
- **Fehler**: Die Zeile kann nicht importiert werden (zum Beispiel ein fehlender Name oder ein Land, das kein 2-Buchstaben-Code ist). Korrigieren Sie sie in der Datei und importieren Sie erneut.

Nur Zeilen mit **Erstellen** lassen sich anhaken.

Wie „bereits vorhanden“ bestimmt wird:

- **Partner** mit Steuernummer werden anhand der **Steuernummer** abgeglichen (Formatierungsunterschiede wie Leerzeichen oder Bindestriche werden ignoriert). Partner ohne Steuernummer werden anhand des **Namens** abgeglichen.
- **Rechnungs- und Cashflow-Kategorien** werden anhand des **Namens** abgeglichen, innerhalb der gerade importierten Art (Rechnung vs. Cashflow).

Da vorhandene Datensätze übersprungen und nicht geändert werden, können Sie dieselbe Datei gefahrlos erneut ausführen - der zweite Durchlauf meldet einfach alles als **Vorhanden**.

## Richtung der Kategorie

Eine Kategorie kann für **Einnahmen**, für **Ausgaben** oder für **beide** verwendet werden. Enthält Ihre Datei eine Richtungsspalte, liest der Import sie auf Deutsch, Ungarisch und Englisch. Groß- und Kleinschreibung sowie Akzente und Umlaute spielen keine Rolle, `Erträge`, `ERTRAGE` und `erträge` sind also dasselbe Wort.

| In der Datei | Die Kategorie wird |
|---|---|
| `Einnahme`, `Ertrag`, `Erlös`, `income`, `revenue`, `sales`, `bevétel`, `árbevétel` | **Einnahme** |
| `Ausgabe`, `Aufwand`, `Kosten`, `expense`, `cost`, `kiadás`, `költség`, `ráfordítás` | **Ausgabe** |
| `beide`, `Einnahme und Ausgabe`, `both`, `income and expense`, `mindkettő`, `bevétel és kiadás` | **Beide** |
| leere Zelle oder gar keine Richtungsspalte | **Beide** |
| jedes andere Wort | **Beide**, und die Zeile erhält den Hinweis **Richtung nicht erkannt** |

Gängige Pluralformen funktionieren ebenfalls (`Ausgaben`, `expenses`, `kiadások`).

Im Schritt **Prüfen** sehen Sie über der Tabelle drei Zahlen: wie viele Kategorien laut Datei Einnahme werden, wie viele Ausgabe und wie viele für beide verwendbar sind. Konnten einige Richtungszellen nicht gelesen werden, nennt ein gelber Hinweis die Anzahl. Jede Zeile zeigt ihre Richtung in der Spalte **Richtung**, und dort können Sie sie vor dem Anlegen ändern: Drücken Sie **Alt+↓** auf der Zeile (Option+↓ auf einem Mac) oder klicken Sie auf den Pfeil in der Zelle, und wählen Sie **Einnahme**, **Ausgabe** oder **Beide**. Der Wert aus der Datei bleibt der Vorschlag, und die Zahlen über der Tabelle zeigen weiterhin, was in der Datei steht.

Wörter wie `eingehend` / `ausgehend`, `in` / `out`, `incoming` / `outgoing`, `bejövő` / `kimenő` und `debit` / `credit` werden **absichtlich nicht** gelesen. Sie zeigen je nach Datei in entgegengesetzte Richtungen: Eine Eingangsrechnung ist eine Ausgabe, ein Geldeingang auf dem Kontoauszug dagegen eine Einnahme. Verwenden Sie stattdessen eines der Wörter aus der Tabelle.

Eine für beide verwendbare Kategorie wird bei Ausgangs- und Eingangsrechnungen gleichermaßen angeboten. Die meisten Kategorien gehören nur zu einer Seite, prüfen Sie daher die Zahl bei **beide**, bevor Sie erstellen. Die Richtung einer Kategorie können Sie jederzeit im Bearbeitungsformular der Kategorie ändern.

## Über mehrere Spalten verteilte Adressen

Büro-Exporte teilen eine Adresse oft auf mehrere Spalten auf - Postleitzahl, Ort, Straße, Hausnummer. Im Schritt **Spalten zuordnen** können Sie **Adresse** mehreren Spalten zuordnen: klicken Sie auf **+ Spalte hinzufügen** und wählen Sie jeden Teil. Die Teile werden der Reihe nach zu einer einzigen Adresse zusammengefügt (zum Beispiel wird aus `1051`, `Budapest`, `Váci utca`, `1` „1051, Budapest, Váci utca, 1"). Der Schritt **Prüfen** zeigt das zusammengesetzte Ergebnis.

## Hinweise & Einschränkungen

- Der Import fügt Datensätze hinzu; er aktualisiert vorhandene nicht. Um einen bereits vorhandenen Partner oder eine Kategorie zu ändern, bearbeiten Sie ihn direkt auf seiner Seite.
- Beim Import von Partnern nennt das Ergebnis auch, welche USt-Gruppen anhand der Steuernummern zugeordnet wurden und bei wie vielen Partnern ohne Steuernummer Sie die USt-Gruppe unter **Partner** prüfen sollten.
- Ob Kategorien als **Rechnungs-** oder **Cashflow-Kategorien** importiert werden, entscheidet die Seite, von der aus Sie starten, nicht der Inhalt der Datei.
- Bei Partnern ist nur der **Name** erforderlich. Steuernummer, Land und Adresse sind optional, aber ihr Ausfüllen macht den automatischen Abgleich später deutlich zuverlässiger - siehe [Partner verwalten](/partners).
